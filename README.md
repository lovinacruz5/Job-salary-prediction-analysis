# Job-salary-prediction-analysis
SQL project on job salary prediction dataset exploring salary trends, experience impact, and role-based insights.

Completed a SQL project using Job Salary Prediction Dataset to gain insights into salary trends across different roles and industries.
Used SQL Clauses and Aggregation functions like SELECT, GROUP BY, ORDER BY, COUNT, SUM, AVG, MIN, MAX, WHERE, LIMIT and HAVING.

📊 Key Tasks Performed:
.Analysed salary distribution across:
.Job roles
.Experience levels
.Industries
.Company sizes
.Created two tables to perform joins such as INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN.
